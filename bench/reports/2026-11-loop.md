# Loop and tool measurements — November 2026

Ask's own loop, 15 tasks × 3 runs, before → after the new prompt and Git tool:

| Model | Passed | Review | Steps | Input tokens | Seconds | Answer chars |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| GLM-5.3 | 43 → 45 of 45 | 1 → 3 of 3 | 8.1 → 6.5 | 73k → 41k | 41 → 25 | 2460 → 1697 |
| MiniMax-M3 | 42 → 45 of 45 | 0 → 3 of 3 | 8.6 → 6.6 | 112k → 104k | 24 → 15 | 2537 → 1785 |

Read-only reviews couldn't see the diff before the Git tool. Claude Code (Haiku) and
Codex were near the ceiling (22/22 and 28/30). Reading long web pages in 16k pieces
brought input from 269k to around 140k at one more step.

The original caller benchmark named ask explicitly, loaded the skill directly into
the prompt, and did not offer Claude Code a native subagent tool. The revised skill
raised Claude Code from 4/6 to 6/6 and increased average handoff length from 271 to
390 characters; Codex passed 6/6 with both. These aren't comparable to the later
[caller pilot](2026-11-callers.md).

## Compaction

One `opencode-go/glm-5.3` run passed all six checks in 22.9 seconds (1,969 input, 2,049
output tokens, including 20 cached input). It said the interrupted write's outcome
was unknown and should be checked. This single synthetic case does not compare
compacted and uncompacted context or establish reliability on other models.

## Extraction

One run with `opencode-go/glm-5.3` and helper `opencode-go/glm-5.3-flash`, three repetitions:

| Variant | Correct | Median seconds | Total input + output tokens |
| --- | ---: | ---: | ---: |
| Direct text (all pages) | 12/12 | 1.594 | 39,779 |
| Same-model extraction | 9/12 | 4.186 | 45,101 |
| Smaller-helper extraction | 7/12 | 7.179 | 46,154 |

The direct-text arm supplies all pages together; it is not a network or iterative-fetch
benchmark. Variants ran concurrently by fixture; provider scheduling and a 700-token
final-answer budget may have affected results. Failed answers reported incomplete
extraction or generation. These runs don't establish a general benefit for helpers.
